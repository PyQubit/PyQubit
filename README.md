## 🚀 Flagship Project

### Innoverse-2025 — AI Emotion-to-Art

A multimodal AI pipeline combining emotion understanding, speech processing and generative AI.

### Tech Stack

`Python` · `Gradio` · `Ollama` · `LLMs` · `Whisper` · `Audio` · `Replicate API`

### Architecture

```text
                 ┌─────────────┐
Text ───────────►│             │
                 │   Emotion   │
Voice ──────────►│ Understanding│───► AI Interpretation
                 │             │
Image ──────────►│             │
                 └─────────────┘
                         │
                         ▼
                Generative Artwork
```

### Key Features

* Multimodal emotion recognition
* Speech-to-text processing
* AI-based emotion interpretation
* Generative artwork synthesis
* Interactive AI interface
